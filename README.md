# 🐍 SnakeGame

---

## 📖 Description

| English                                                                                                                                                                                                                                                                  | عربي                                                                                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **SnakeGame** is a JavaFX application that implements the classic **Snake** game. The player controls a snake that moves around the game board and eats food that appears at random locations. The game ends when the snake collides with the wall or with its own body. | **SnakeGame** هو تطبيق مكتوب باستخدام **JavaFX** يُحاكي لعبة **Snake** الكلاسيكية. يتحكم اللاعب بثعبان يتحرك داخل لوحة اللعب ويأكل الطعام الذي يظهر عشوائيًا. تنتهي اللعبة عند اصطدام الثعبان بالجدار أو بجسمه. |

---

## 🎮 Game Mechanics

|                                                                                                                                                                                                                                                                                                                   |                                                                                                                                                                                                                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| • The snake moves continuously in the current direction.<br>• When the snake eats food:<br>  – The snake grows in length.<br>  – The player’s score increases.<br>  – The snake’s speed may increase based on the score.<br>• The game ends when:<br>  – The snake hits the wall.<br>  – The snake collides with itself. | • يتحرك الثعبان بشكل مستمر حسب الاتجاه الحالي.<br>• عند أكل الطعام:<br>  – يزداد طول الثعبان.<br>  – تزداد النقاط (Score).<br>  – قد تزداد سرعة الثعبان حسب النقاط.<br>• تنتهي اللعبة عند:<br>  – الاصطدام بالجدار.<br>  – الاصطدام بجسم الثعبان نفسه. |

---

## ⚙️ Game Configuration

| English                                                                                                                                                                                                           | عربي                                                                                                                                                                                            |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The **SnakeGame** class contains constants and variables that control:<br>• Snake speed<br>• Game board size<br>• Snake position and direction<br>• Food position and color<br>• Game state (running / game over) | تحتوي فئة **SnakeGame** على مجموعة من الثوابت والمتغيرات التي تتحكم في:<br>• سرعة الثعبان<br>• حجم لوحة اللعب<br>• اتجاه وموقع الثعبان<br>• موقع الطعام ولونه<br>• حالة اللعبة (تشغيل / انتهاء) |

---

## 🧱 Classes Description

### 1️⃣ SnakeGame Class

| English                                                                                                                                                                                                                      | عربي                                                                                                                                                                                       |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| The main class of the application.<br><br>**Methods:**<br>• `start()` – Creates the start screen.<br>• `startGame()` – Starts the game by creating the board, updating movement, rendering frames, and detecting collisions. | الفئة الرئيسية للتطبيق.<br><br>**الدوال:**<br>• `start()` – إنشاء شاشة البداية.<br>• `startGame()` – بدء اللعبة من خلال إنشاء اللوحة، تحريك الثعبان، تحديث الإطارات، والتحقق من التصادمات. |

---

### 2️⃣ Corner Class

| English                                                                                                                                                                                                        | عربي                                                                                                                                                                 |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A nested class representing a single cell on the game board.<br><br>**Attributes:**<br>• `int x` – horizontal position<br>• `int y` – vertical position<br><br>**Constructor:** Initializes the cell position. | فئة داخلية تمثل خلية واحدة في لوحة اللعب.<br><br>**المتغيرات:**<br>• `int x` – الموقع الأفقي<br>• `int y` – الموقع العمودي<br><br>**Constructor:** يهيئ موقع الخلية. |

---

### 3️⃣ Speedup Class

| English                                                                                                                                                                                                                        | عربي                                                                                                                                                                                                         |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| A class used to increase the snake’s speed as the score increases.<br><br>**Method:** `increaseSpeed(int score)`<br>• Score = 3 → speed = 7<br>• Score = 6 → speed = 10<br>• Score = 8 → speed = 14<br>• Otherwise → no change | فئة مسؤولة عن زيادة سرعة الثعبان مع تقدم النقاط.<br><br>**الدالة:** `increaseSpeed(int score)`<br>• Score = 3 → السرعة = 7<br>• Score = 6 → السرعة = 10<br>• Score = 8 → السرعة = 14<br>• غير ذلك → لا تغيير |
